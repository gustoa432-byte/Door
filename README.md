# Door — Real-Time Tactile Connection 🌌

> **Тактильная и сенсорная связь в реальном времени через экран.**  
> Door позволяет двум людям или человеку и цифровому компаньону прикоснуться друг к другу сквозь расстояние, ощущая взаимное присутствие через свет, процедурный звук и вибрацию.

## ✨ О проекте

Современные мессенджеры и видеозвонки перегружены текстом и визуальным шумом. **Door** убирает всё лишнее, создавая медитативное пространство чистого невербального контакта.

Пользователи касаются экрана и видят движение ауры друг друга. Когда траектории сближаются, математическая формула резонанса активирует физическое притяжение частиц, процедурную гармонию Web Audio API и тактильный виброотклик.

## 🎮 Режимы работы

### 1. 👥 Комната для двоих (P2P / H2H)
* **Создание комнаты:** Генерация уникального 6-значного кода или ссылки в один клик.
* **Сверхнизкая задержка:** Передача координат в реальном времени через `Socket.io` с оптимизацией `volatile.emit`.
* **Сенсорный резонанс:** При синхронном движении активируются световые пульсации и пространственный звук.
* **Адаптивный Lite-режим:** При нестабильном соединении (ping > 150ms) приложение автоматически переключается в портальный Lite-режим для сохранения тактильной связи без подёргиваний.

### 2. 🤖 0n<3 (Цифровой компаньон)
* Автономный AI-партнёр для одиночного контакта.
* **Echo Engine:** Воспроизведение органических траекторий касаний (`EchoService`).
* **Поведенческий автомат состояний:**
  * `wandering` — спокойное исследование пространства;
  * `evading` — игривое уклонение от резких движений;
  * `caught` — удержание контакта и синхронизация;
  * `fleeing` — резкий побег при попытке резкого захвата;
  * `boredom_routine` & `watching` — скука и наблюдение при неподвижности пальца пользователя.
* **Дофаминовый профилинг:** AI анализирует темп и терпеливость пользователя за первые 15 секунд сессии, подстраивая радиус дистанции и поведение.

## 🔬 Математика и механика резонанса (`Formula.ts`)

Ядром взаимодействия является алгоритмическая модель `_0xF`:
* **Энтропия ($\_e$):** Мера хаоса между двумя точками. Снижается при синхронном, плавном сближении.
* **Интенсивность намерения ($\_i$):** Скорость сближения и направленность векторов движения.
* **Адреналин ($\_a$) и Резонанс ($\_ir$):** Пороговое состояние единства, запускающее вспышки частиц и глубокие аккорды синтезатора.
* **Пульс синхронизации ($\_ib$):** Ритмический пульс, генерирующий синхронные тактильные импульсы в браузере.

## 🎧 Аудиосистема (`useResonator.ts`)

Чистый процедурный синтез на **Web Audio API** без сторонних тяжелых аудиофайлов:
* **Основной тон:** Управляемый синусоидальный осциллятор с плавной модуляцией высоты в зависимости от расстояния.
* **Саб-бас (Sub-bass):** Низкочастотный гул (55 Гц) для ощущения физического веса прикосновения.
* **Стерео-хорус и фильтрация:** Biquad-фильтры, реагирующие на скорость перемещения пальца.
* **Гармонический резонанс:** При схождении траекторий включается мягкий гармонический интервал (квинта/октава) с мягким спадом.

## 🛠 Технологический стек

* **Frontend:**
  * React 19 + TypeScript
  * Vite 6 (Fast HMR & Optimized Build)
  * Tailwind CSS v4
  * Motion (`motion/react`) — плавные переходы UI
  * Lucide React — системные пиктограммы
* **Backend:**
  * Node.js + Express
  * Socket.io 4.8 (WebSocket с поддержкой volatile пакетов для touch-координат)
* **Аппаратные API браузера:**
  * HTML5 Canvas 2D (песочные частицы со следами затухания)
  * Web Audio API (интерактивный синтез звука)
  * Vibration API (`navigator.vibrate`)
  * Touch Events & Pointer Events (`touch-action: none`)

## 🚀 Быстрый старт

### Предварительные требования
* Node.js 18+
* npm или yarn

### Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/your-username/door.git
   cd door
   ```

2. **Установите зависимости:**
   ```bash
   npm install
   ```

3. **Запустите локальный сервер разработки:**
   ```bash
   npm run dev
   ```
   Сервер запустится на `http://localhost:3000`.

4. **Сборка для продакшена:**
   ```bash
   npm run build
   ```

5. **Запуск собранного приложения:**
   ```bash
   NODE_ENV=production node server.ts
   ```

## 📱 Оптимизация для мобильных устройств

Приложение создано Mobile-First и оптимизировано для работы в браузере смартфона (включая Telegram Web App / Safari / Chrome):
* Отключены системные свайпы и паразитные зумы: `viewport-fit=cover`, `maximum-scale=1.0`, `user-scalable=no`.
* Слой Canvas использует лёгкий 2D-рендеринг с постоянным пулом частиц (до 500 элементов), не перегружая мобильный GPU и аккумулятор.
* Защита от троттлинга частоты кадров через дельту времени `performance.now()`.
